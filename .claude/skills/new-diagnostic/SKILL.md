# /new-diagnostic — 선수학습 진단지 추가

## 역할

이미 구현된 학기·단원의 `선수학습` 학습지를 모아, 단원별 진단지를 만든다. 목적은 본 단원 수업 전 선수학습 결손을 빠르게 확인하는 것이다.

진단지는 기존 학습지를 그대로 복사하지 않는다. 각 선수학습 항목에서 4문항씩 뽑아 A4에 빽빽하지만 읽기 좋게 배치한다.

## 입력

1. **학기**: 예 `g5-1`
2. **범위**: 전체 단원 또는 특정 단원
3. **문항 수**: 기본값은 선수학습 항목당 4문항
4. **배치 규칙**:
   - 한 단: 최대 24문항
   - 한 장: 2단, 최대 48문항
   - 48문항 초과 시 2장 이상 가능
   - 페이지 수는 가능한 줄인다
5. **선수학습이 없는 단원**: 진단지 없음

## 분석 절차

구현 전에 `/analysis` 흐름으로 현재 상태를 먼저 점검한다.

1. `AGENTS.md`, `app/ARCHITECTURE.md`, `CURRICULUM.md`를 읽고 금지 사항과 출처 기준을 확인한다.
2. 대상 학기 catalog에서 각 단원의 `선수학습(...)` 묶음을 센다.
3. 선수학습 항목 수 × 4로 단원별 총 문항 수를 계산한다.
4. 다음 기준으로 페이지를 산정한다.

| 기준 | 계산 |
|---|---:|
| 한 항목 | 4문항 |
| 한 단 | 6항목 = 24문항 |
| 한 장 | 12항목 = 48문항 |
| 13항목 이상 | 2장 이상 |

5. 선수학습 항목이 0개면 그 단원은 `진단지 없음`으로 기록한다.
6. 기존 generator 반환 형태를 확인해 압축 렌더링이 가능한지 분류한다.

## 구현 원칙

- 제너레이터는 기존 것을 재사용한다. 새 진단지 전용 generator는 꼭 필요한 경우에만 추가한다.
- 데이터와 표현을 분리한다. generator에서 진단지 HTML을 만들지 않는다.
- 진단지 렌더링은 `renderers.js`, `templates.js`, `layout.js`, CSS 중 기존 역할에 맞는 곳에 둔다.
- catalog에는 진단지를 별도 `kind` 또는 기존 구조와 호환되는 방식으로 등록한다.
- 단원별 선수학습이 없으면 catalog에 진단지 항목을 억지로 추가하지 않는다.
- 본단원 항목으로 진단지를 만들지 않는다. 진단지는 선수학습 전용이다.
- 출처 정보는 필요할 때 항목 제목에 한 번만 표시한다. 문제마다 반복하지 않는다.
- 빌드 도구, npm/yarn 의존성, TypeScript, 번들러를 추가하지 않는다.

## 압축 렌더링 기준

기존 학습지의 큰 풀이 과정을 그대로 넣으면 한 장에 들어가지 않는다. 진단지는 아래처럼 작게 바꿔 출력한다.

| 기존 형태 | 진단지 표현 |
|---|---|
| `horizProblem` | 한 줄 계산식 |
| 세로셈 PDF 데이터 | `a + b = □`, `a × b = □` 같은 한 줄 계산식 |
| 나눗셈 세로셈 | `a ÷ b = □` 또는 `a ÷ b = □ ... □` |
| 분수 한 줄 계산 | 기존 분수 표기를 줄인 compact row |
| 분수 단계 풀이 | 진단 목적에 필요한 최소 식과 답칸만 표시 |
| 도형/개념 문제 | 그림이나 조건이 너무 크면 진단지 전용 compact 표현을 추가 |

압축해도 학생이 무엇을 풀어야 하는지 모호하면 그 항목은 진단지 전용 compact 템플릿을 만든다.

## catalog 등록 기준

진단지는 일반 학습지와 구분되는 ID를 쓴다.

```js
학습지('선수학습 진단지', ..., {
  id: 'u1_pre_diagnostic',
  kind: 'diagnostic',
})
```

학기 prefix는 catalog 빌더가 자동으로 붙이므로 `g5-1_`를 직접 쓰지 않는다.

선수학습 항목을 참조해야 한다면 기존 `선수학습(...)` 묶음의 entries를 기준으로 한다. 같은 정보를 별도 배열에 중복 작성하지 않는 것을 우선한다.

## 검증

구현 후 최소한 다음을 확인한다.

```bash
node .claude/scripts/audit.mjs
node .claude/scripts/validate.mjs 1000
```

자연수 계산 generator를 새로 만들거나 고쳤다면:

```bash
node .claude/scripts/validate.mjs 5000
```

화면과 인쇄는 로컬 서버에서 확인한다.

```bash
python3 -m http.server 8000 --directory app
```

브라우저 확인 항목:

- 진단지가 있는 단원에만 표시되는가
- 선수학습이 없는 단원에는 표시되지 않는가
- 2단 배치가 화면과 인쇄에서 유지되는가
- 한 단 24문항, 한 장 48문항 기준이 지켜지는가
- 48문항 초과 단원은 다음 장으로 자연스럽게 넘어가는가
- 정답 보기 전/후 레이아웃이 깨지지 않는가
