# 분석 기록: 2학년 자릿값 모형 배열 개선 계획

- **일시**: 2026-05-04
- **요구사항 원문**: `/request 2-1 1. 세 자리수 / 2-2 1. 네 자리 수 / 모형 보고 숫자 맞히는 문제지 모두 공통의 문제가 발견됨 / 모형 배열이 비효율적임 / 효율적인 배열을 위한 계획을 세워봐라`
- **판정**: ✅ 안전

## 영향 범위

| 대상 | 영향 수준 | 상세 |
|---|---:|---|
| `app/js/helpers.js` | 낮음 | `placeValueModelHtml()`이 세 자리·네 자리 모형 문제의 공통 HTML을 만든다. |
| `app/css/worksheet.css` | 중간 | 자릿값 모형 배치 규칙 대부분이 CSS에 있다. 백 모형 규칙이 현재 적용되지 않는 문제도 있다. |
| `app/js/generators/g2-1/u1.js` | 낮음 | 세 자리 수 모형 문제는 공용 헬퍼를 호출한다. 직접 수정은 최소화 가능하다. |
| `app/js/generators/g2-2/u1.js` | 낮음 | 네 자리 수 모형 문제도 같은 공용 헬퍼를 호출한다. 직접 수정은 최소화 가능하다. |
| `design.md` | 낮음 | “모형 보고 수 쓰기” 원칙과 자릿값 모형 표현 기준이 이미 적혀 있다. 필요하면 배열 기준만 보강한다. |

## 현재 확인한 문제

| 문제 | 근거 |
|---|---|
| 백 모형이 가로 묶음이 아니라 세로 1열로 길게 쌓인다. | `app/css/worksheet.css` 436행의 남는 `}` 때문에 `.base-ten-hundreds` 규칙이 CSSOM에서 빠진다. 브라우저 확인 시 `.base-ten-hundreds`의 computed display가 `grid`이고 `max-width`가 `none`이었다. |
| 자릿값 그룹 전체가 줄바꿈 중심이라, 숫자별 배열이 들쭉날쭉하다. | `placeValueModelHtml()`은 천·백·십·일 그룹을 순서대로 붙이고, `.base-ten-model`은 `inline-flex + flex-wrap`으로 감싼다. |
| 네 자리 수에서 큰 숫자 조합은 모형 높이가 너무 커진다. | 예: 천 8개, 백 8개, 십 6개, 낱개 9개가 한 문제 안에서 약 318px × 376px까지 커졌다. |
| 학생이 “몇 개씩 묶였는지” 빠르게 읽기 어렵다. | 백·십·일이 각자 다른 방향과 폭으로 감싸져 자리값별 시선 이동이 길다. |

## 점검 결과

| 점검 항목 | 결과 | 근거 |
|---|---|---|
| 기존 약속 | ✅ | `placeValueModelHtml({ thousands, hundreds, tens, ones })` 입력 형태는 유지하면 된다. |
| 연결 관계 | ✅ | 공용 헬퍼와 CSS 수정만으로 생성기 구조를 바꾸지 않아도 된다. |
| 데이터 모양 | ✅ | 저장 데이터나 카탈로그 구조 변경 없음. |
| 과거 기록 | ✅ | 기존 문제의 정답 값은 그대로 유지된다. |
| 사용자 흐름 | ✅ | 학년·단원·학습지 선택 흐름은 그대로 둔다. |
| 되돌리기 어려움 | ✅ | 화면 표현 수정이라 되돌리기 쉽다. |

## 제시한 배열 방향

- 백 모형: 1~4개는 한 줄, 5~9개는 `5 + 나머지` 또는 `3열 그리드` 중 하나로 통일한다.
- 천 모형: 1~5개는 한 줄, 6~9개는 `5 + 나머지` 2줄로 통일한다.
- 십 모형: 1~5개는 한 줄, 6~9개는 `5 + 나머지` 2줄로 통일한다.
- 낱개: 현재처럼 3열도 가능하지만, 다른 자릿값과 맞추려면 `5 + 나머지` 흐름이 더 빠르게 세어진다.
- 전체 모형: `천/백`과 `십/일`을 같은 baseline에 억지로 붙이지 말고, 큰 단위 줄과 작은 단위 줄로 나누면 문제 높이를 줄이고 읽는 순서도 안정된다.

## 권장 구현안

1. 먼저 CSS 오류를 고쳐 백 모형 규칙이 적용되는지 확인한다.
2. 그 다음 공통 클래스만으로 해결 가능한지 본다.
3. 개수별 배열 제어가 필요하면 `placeValueModelHtml()`에서 각 그룹에 `data-count`를 붙인다.
4. `data-count` 기반 CSS로 천·백·십·일을 모두 5개 단위 묶음 기준으로 정렬한다.
5. 2-1, 2-2 각각 대표 난수와 최대 조합에 가까운 숫자를 화면에서 확인한다.

## 제시한 대안

- 단순 수정안: 남는 `}` 제거 + `.base-ten-hundreds`를 flex-wrap으로 적용한다.
- 권장 수정안: CSS 오류 수정 + 자릿값 그룹별 `5 + 나머지` 배열 체계를 도입한다.
- 큰 수정안: 모형 HTML 구조를 행 단위로 재구성해 `천/백` 행과 `십/일` 행을 명시적으로 나눈다.
