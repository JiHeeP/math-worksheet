# 분석 기록: 소수 곱셈·나눗셈 격자 디자인 보정

- **일시**: 2026-05-05
- **요구사항 원문**: 소수점이 찍히는 선을 굳이 진하게 처리하지 말 것. 소수의 나눗셈 격자 크기가 작으므로 애초에 폰트를 '크게'로 설정할 것. 6-2-3 소수의 나눗셈 세로셈에 불필요한 가로셈식이 있으면 전체 검증하고 제거할 것. 소수의 곱셈이나 나눗셈에서 불필요한 격자를 줄이기 위해 격자는 그대로 두되 중간의 진한 선은 긋지 말 것.

## 현재 문제 원인

- `.decimal-point-on-line::before`가 소수점 위치에 별도 진한 세로선을 그리고 있어, 사용자는 점이 선 위에 있다는 것보다 해당 선만 강조된 것으로 보게 된다.
- `renderDecimalVertical()`은 `decimalWorkLineNode()`를 추가해 곱셈 중간에 진한 가로선을 두 번 그린다.
- `renderDecimalLongDiv()`은 나눗셈 작업 영역 내부에도 `decimalWorkLineNode()`를 반복 추가한다.
- `renderDecimalLongDiv()`은 `problem.shift`가 있으면 `.decimal-shift-row`로 `원래식 = 변환식` 형태의 가로셈식을 출력한다. 검색 결과 `shift: true`는 `app/js/generators/g6-2/u3.js`의 2개 생성기에만 있다.
- 소수 나눗셈은 현재 `--cell: 20px * font-scale`, `font-size: 17px * font-scale`이고, UI 기본 선택은 `보통(1)`이다. 그래서 6-1/6-2 소수 나눗셈을 처음 열면 작아 보인다.

## 제시한 대안

- **권장안**: 격자는 그대로 두고, 소수점은 점만 선 위에 표시한다. 중간 진한 선과 가로셈식은 제거한다. 소수 나눗셈 학습지만 기본 글자 크기를 `크게`로 자동 설정한다.
- **보수안**: UI 기본 글자 크기는 그대로 두고 CSS에서 소수 나눗셈 칸만 조금 키운다. 하지만 사용자가 컨트롤에서 보는 값은 `보통`인데 화면은 커져 있어 덜 직관적이다.
- **비권장안**: 소수점 위치의 진한 선만 흐리게 하고 중간 진한 선을 유지한다. 사용자가 지적한 “불필요한 선” 문제가 남는다.
