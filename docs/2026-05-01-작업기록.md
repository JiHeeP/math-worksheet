## 4. 새 기능: 선수학습 칩 패널

### 동작

본단원 학습지를 선택하면 컨트롤바 아래에 선수학습 칩이 표시됨.

```
[2단원 · 본단원] [교과 차시: 1~2차시 ...]
선수학습  [5-1] 약분과 통분 ← 파란 버튼 (클릭 가능)
          [4-2] 분수의 덧셈과 뺄셈(1) ← 회색 라벨 (외부)
```

| 칩 종류 | 모양 | 클릭 동작 |
|---|---|---|
| 같은 학기의 단원 | 파란 버튼 | 그 단원의 첫 학습지로 이동 |
| 같은 학기의 학습지 | 파란 버튼 | 그 학습지로 직접 이동 |
| 다른 학기 (외부) | 회색 라벨 | 표시만 (해당 학기 미구현) |

### 카탈로그에서의 표현

```js
학습지('분모 다른 진분수의 덧셈 (합이 1 미만)', T.fracLcdStep, genFracAddLt1, {
  id: 'u5_main_add',
  prereqs: [
    unitRef('u4'),                              // [5-1] 약분과 통분
    ext('[4-2] 분수의 덧셈과 뺄셈(1)'),         // 외부 (표시만)
  ],
}),
```

3가지 헬퍼 (catalog.js):
- `unitRef('u4')` — 같은 학기 단원
- `sheetRef('u5_main_add')` — 같은 학기 특정 학습지
- `ext('[4-2] ...')` — 외부 학기 (현재는 라벨만)

## 11. 한 번 더 정리 — 의도

**왜 이 작업이 필요했는가?**
- 5학년 1학기 한 학기만 있는 앱을 **1~6학년 12학기** 전체로 확장하기 위함.
- 학년이 늘어나도 단원 ID 충돌이 없고, 새 학기 추가가 **폴더 1개 + 파일 1개**로 끝나도록 구조 정비.

**왜 선수학습을 화면에 보여주는가?**
- 비개발자(부모/교사) 사용자가 **어떤 학습지가 어느 단원의 선행인지** 한 화면에서 알 수 있어야 학습 흐름을 짤 수 있음.
- 5-1만 봐도 단원 간(예: 분수 덧셈 → 곱셈) 의존이 큼. 6-2까지 가면 더 복잡해질 것.

**무엇을 보존했는가?**
- 기존 5-1 학습지 79개 모두 동작 그대로. 79개 ID에 prefix만 추가됨.
- 인쇄 출력 정책(차시 분리 미노출, 단순 컨트롤바)은 그대로.
