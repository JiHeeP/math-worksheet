# 1·2학년 학기 도입 계획

> 작성: 2026-05-02
> 의사결정: Phase 1~4 모두 진행. Phase 4 (구구단 단 선택) 는 **단별 학습지 분리(드롭다운) 방식** 으로 구현 (모달 X).

## 배경

외부에서 1·2학년용 계산 연습지 단일 HTML 파일을 받음. 그 안의 자산을 우리 학년·학기 다중 지원 구조로 이식.

원본은 `problemType` 드롭다운으로 모든 학습지를 한 페이지에서 처리하던 단일 파일. 우리 구조는 학년·학기·단원·학습지 4단 캐스케이드 + 카탈로그 빌더. 따라서 **로직만 추출, UI/디자인은 우리 톤 유지**.

함께 보기: [CURRICULUM.md](../CURRICULUM.md), [CLAUDE.md](../CLAUDE.md), [app/ARCHITECTURE.md](../app/ARCHITECTURE.md)

### generator 팩토리 패턴

```js
// 단을 매개변수로 받는 팩토리
function genGugudanFixed(dan) {
  return function() {
    const m = rand(1, 9);
    return horizProblem(`${dan} × ${m}`, numBlank(dan * m));
  };
}

// 카탈로그에서:
학습지('2단', genGugudanFixed(2), { id: 'u2_main_gugudan_2' }),
학습지('3단', genGugudanFixed(3), { id: 'u2_main_gugudan_3' }),
// ...
```

### 0단·1단 처리
원본은 0단·1단도 옵션으로 제공했지만, 2022 개정 교육과정에서 **곱셈구구는 2~9단** 이 표준. 0단·1단은 카탈로그에서 제외.

## 가져오지 않을 것

| 항목 | 이유 |
|---|---|
| HTML/CSS 디자인 통째로 | 우리 톤이 더 정돈됨. 시각화 아이디어만 차용 |
| 컨트롤바 구조 | 우리 것이 학년·학기 다중 지원 구조 |
| `_horiz_prac`, `isPractice2` 같은 동적 분기 | 우리는 학습지 ID 로 분리. 한 generator = 한 학습지 |
| `displayTitle.replace(...)` 후처리 | `buildSheetTitle` 이 이미 깔끔하게 처리 |
| 인쇄 스타일 | 우리 `@media print` 가 이미 검증됨 |
| 구구단 모달 UI | 단별 학습지 드롭다운 분리 방식으로 대체 |

## 작업 패턴 (각 Phase 공통)

```
1. Generator 작성 → node --check
2. Catalog 작성 → node --check
3. catalog.js 의 GRADES 배열 등록
4. mw_validate.mjs 5,000회 회귀 테스트 통과 확인
5. 브라우저 새로고침 후 시각 확인
6. CURRICULUM.md 학기별 정렬 섹션 갱신 (해당 학기에 ★ 추가)
7. CHANGELOG.md 에 항목 추가
8. Commit + push
```

CLAUDE.md "수학 결과 무결성" 규칙 준수 필수:
- 자연수 계산 결과: 음수/0/소수 X
- 받아올림/내림 케이스는 단계 풀이 템플릿 사용 (Phase 3 후)

## 작업량·우선순위 평가

| Phase | 예상 시간 | 의존성 | 추천 순서 |
|---|---|---|---|
| Phase 1 (1학년 덧·뺄셈) | 보통 (제너레이터 7~8개 + 카탈로그) | 없음 | **첫 번째** |
| Phase 2 (2학년 덧·뺄셈) | 보통 (제너레이터 5~6개 + 카탈로그) | Phase 1 권장 | **두 번째** |
| Phase 3 (시각화 통합) | 큼 (SVG 헬퍼 + 6~8개 새 템플릿) | Phase 1·2 후 | **세 번째** |
| Phase 4 (구구단 단별) | 작음 (팩토리 1개 + 카탈로그 10항목) | Phase 2 와 함께 | **Phase 2 동시** |

### 효율적 일정
- Phase 1 + Phase 2 + Phase 4 를 묶어 **수와 연산 1·2학년 일괄 채우기** (시각화 없이 한 줄 풀이)
- 그 후 Phase 3 시각화로 일괄 업그레이드

이 방식이면 1·2학년 학기가 짧은 시간에 사용 가능 상태가 되고, 시각화는 점진적으로 추가됨.

## 미정 사항 (사용자 결정 필요시)

- **수 세기 단원** (1-1 u1, u5, 1-2 u1, 2-1 u1, 2-2 u1): 원본에 없는 디자인. 학습지 형태 결정 필요. 1차에서는 보류.
- **곱셈(1) 묶어 세기** (2-1 u6): 시각화 필요. 1차 보류.
- **규칙찾기** (1-2 u5, 2-2 u6): 별도 디자인. 1차 보류.

위 단원들은 Phase 5 또는 별도 작업으로 분리.
